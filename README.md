# Homebrew Tap for coppercli

This is the Homebrew tap for [coppercli](https://github.com/thomergil/coppercli), a CLI tool for PCB milling with GRBL CNC machines.

## Installation

```bash
brew tap thomergil/coppercli
brew install coppercli
```

## Updating

```bash
brew update
brew upgrade coppercli
```

## Uninstalling

```bash
brew uninstall coppercli
brew untap thomergil/coppercli
```
